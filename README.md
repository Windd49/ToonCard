# 漫劇卡 ToonCard

**把角色卡變成可以遊玩、可以收藏、可以分享的互動漫劇。**

> ⚠️ **開發中**：本專案仍在持續更新，目前還有許多已知與未知的 bug，也有不少功能尚待加入。目前只有用 Google Gemini 模型（Gemini API 與 Vertex AI）測試過，其他文字或圖像服務雖然可以設定，但不保證能正常運作。關閉成人內容時仍可能看到部分 NSFW 角色卡（見「角色卡來源」）。歡迎回報問題。

你扮演主角，AI 演出角色與旁白：角色以立繪登場、隨台詞換表情，劇情走到關鍵場面時換上插圖，匯入自己的音樂後配樂會跟著氣氛切換，每段劇情結束都能選擇接下來怎麼做。角色卡可以直接從 chub.ai 瀏覽，也可以匯入自己的角色卡檔案。

> 玩法與介面參考了現有的 AI 互動漫劇 App 與 SillyTavern 等角色扮演軟體，角色卡來源使用 chub.ai；本程式與它們皆無關聯，詳見文末「聲明」。

### 你是不是也想要……

- 用自己選的 AI 模型玩角色卡，花多少錢由自己決定？
- 想自己架一套 AI 視覺小說，又不想花太多時間研究設定？
- 玩到最後，最想留下來的其實是劇情裡那些畫面？
- 把一路玩出來的故事和圖，分享給朋友一起看、一起玩？

漫劇卡就是為這些需求做的：

- **花費由你決定**：程式本身免費、開源。文字與圖片使用你自己選的 AI 服務（OpenAI 相容 API、Gemini、Vertex AI、Claude、DeepSeek、OpenRouter，或 Ollama 等本機模型），費用直接付給那個服務；也有免金鑰的試玩模型可以先玩看看。設定頁可以看到每個模型的用量與費用估算。
- **打開就能玩**：安裝 Node.js 後雙擊 .bat 就能開始。在「探索」瀏覽 chub.ai 的角色卡，點進去就能開演。立繪、插圖、背景、配樂、狀態欄與選項的演出都已經做好：圖可以用 AI 畫或自己匯入，配樂放進自己的音樂檔就會依氣氛切換。
- **畫面會留下來**：遊玩中畫好或匯入的立繪、插圖與背景都存在這本書裡，下次直接沿用、不用重畫，也能在素材庫集中管理與匯出。
- **整本分享給朋友**：把一本書（角色卡、世界書、立繪與插圖、配樂）連同你的存檔匯出成一個檔案，朋友匯入後就能從你玩到的地方接著看、接著玩。
- **每個選擇都能重來**：任何一回合都能回到當時的選項改選，原本的進度可以另存分支。
- **資料留在自己的電腦**：存檔、圖片與 API 金鑰只存在你的瀏覽器與這個資料夾裡；除了你設定的 AI 服務與 chub.ai，不會送到其他伺服器。

## 開始使用

1. **雙擊「啟動漫劇卡.bat」**（需要先安裝 [Node.js](https://nodejs.org)）。它會開啟 <http://127.0.0.1:8787>，所有 API 請求都經過本機代理，不會被瀏覽器的跨域（CORS）限制擋下。使用期間請保持黑色視窗開著。
   - 更新程式檔後，請關掉黑色視窗再重新雙擊 .bat，才會載入新的 server.js。
   - 沒有 Node.js 也能直接開 `index.html`，但部分 API 會因跨域限制連不上，也不會讀取 `config.local.json`。
   - 想用手機玩：雙擊「啟動漫劇卡（手機也能連）.bat」，手機連同一個 Wi-Fi，打開視窗裡顯示的「手機」網址。
2. 第一次開始故事時會問你要用哪個模型：
   - **免費試玩**：Pollinations 免金鑰，馬上就能玩（速度較慢，模型由 Pollinations 提供，可能隨時變動）。
   - **自己的 API**：到「設定 → 文字模型」填入網址、金鑰、模型，按「測試連線」。或者寫進 `config.local.json`（見下方）。
3. 到「探索」瀏覽 chub.ai，點作品直接進入作品頁（簡介、序章、主角、存檔、作品設定都在這裡），按「開始新故事」。要不要加入書架自己決定（作品頁的「加入書架」或右上角書籤）。第一次開始某個作品時，會先花幾秒整理這個作品的登場人物（可以略過）。

> 用 .bat 開（127.0.0.1:8787）和直接開 index.html 是瀏覽器裡兩個不同的儲存空間，資料不互通。要搬資料，請在「設定 → 資料」匯出備份，再到另一邊匯入。

### config.local.json（自己的設定，集中在本程式資料夾）

個人設定與安全性設定都寫在本程式資料夾的 `config.local.json`：第一次使用時，把 `config.example.json` 複製一份、改名成 `config.local.json` 再修改。用 .bat 開啟時，程式會讀取它，檔案內容有變動就套用一次（右下角會提示），之後仍可在設定頁調整。

- `llm`、`image`、`story`、`audio`、`net`、`chub`：欄位名稱與設定頁相同（例如文字模型、圖像生成、安全過濾、成人內容）。只寫想預先設定的欄位就好；寫了 `apiKey` 就會用這裡的金鑰。
- `server`：本機伺服器的安全性設定，見下方「安全性設定」。
- `vertex`：Vertex AI 的金鑰檔與專案，只給 server.js 用。

例如改用 Vertex AI：

```json
{
  "llm": { "preset": "vertex", "type": "vertex", "location": "global", "model": "gemini-4-argon" },
  "image": { "backend": "vertex", "location": "global", "model": "gemini-nano-banana-2.1" },
  "vertex": { "keyFile": "", "project": "" }
}
```

`config.local.json` 可能含有 API 金鑰，已列在 `.gitignore`，不會上傳到 GitHub。server.js 只把完整內容給這台電腦本身，手機等區網裝置拿到的是去掉金鑰的版本。

## 角色卡來源：chub.ai

- **探索分頁**：直接瀏覽 chub.ai，有全螢幕滑動與格狀兩種模式，也可以篩選語言（中文／英文／日文／韓文）。排序和 chub.ai 網站的「Sort」選單一一對應：熱門趨勢（Trending）、預設推薦（User Default）、下載最多（# Downloads）、人氣最高（Popularity）、最多收藏（# Favorited）、評分最高（Rating）、AI 評分（AI Rating）、最近更新（Update Time）、最新上架（Creation Time）、隨機探索（Random）；篩選條件也和網站的搜尋頁相同（至少 2 個標籤、50 tokens 以上、包含轉載），所以同一種排序看到的順序應該和 chub.ai 一樣（同名的書收在一起的除外；chub.ai 日後改版可能會有差異）。電腦上用滑鼠滾輪或按住拖曳，就能左右滑排序標籤、序章、主角、繼續遊玩這些橫向列。
- **同名的書只顯示一本**：同一個作者重複上傳的同名書（作者更新時常會另外上傳一張）只顯示最新的一本，別人轉載、內容一樣的也收在一起，標「另有 N 個版本」；不同作者、內容不同的同名卡（例如好幾個不同的「Yui」）照樣分開。作品頁的「其他版本」會列出作者的其他版本（最新的標「最新」；這本不是最新的時會提醒），別人上傳的相同內容收在後面，點一下就打開那一本。
- **搜尋**：輸入關鍵字，或直接貼上 chub.ai 角色網址（例如 `https://chub.ai/characters/作者/角色`）。
- **點作品直接進入作品頁**：下載完整的角色卡 PNG（含內嵌世界書）後打開作品頁，可以看簡介、挑序章與主角、直接開始。這時**還沒加入書架**；按「加入書架」才會出現在書架的格子裡，也可以隨時移出書架（存檔與素材都保留）。只是點開看過、沒有存檔也沒有立繪的作品，下次開啟程式時會自動清掉。
- 之後可以在作品頁的選單「從 chub.ai 下載最新版」更新，存檔與立繪會保留。
- **chub.ai 的世界書**：有些卡的 PNG 檔裡放的是作者另外連結的世界書（例如作者自用的那本），不是這張卡自己的。匯入時改用 chub.ai 網站上這張卡自己的內嵌世界書；以前匯入的卡，打開作品頁時會自動檢查一次（自己改過世界書的不會動）。
- **作者附的立繪與插圖**：有些卡在序章或世界書裡放了作者畫好的圖（圖片網址），再叫 AI 輸出 `<img>` 標籤，本程式不會顯示那種標籤。作品頁的「遊玩前設定」（或點存檔時的遊玩前設定）會提示「這張卡附了作者畫的圖」，按「匯入」（匯入過的顯示「管理」）：
  - **先列清單，你決定要哪些**：依來源（世界書條目、序章）分組列出每張圖的縮圖，可以勾選、改名字、改分類（立繪／插圖／背景）；立繪的「造型」就是立繪種類（例如西幻、校服、古風），留空是「平常」。立繪要填角色名，角色不在角色池時會加進去。預設勾選還沒匯入的圖與上次失敗的圖，已匯入的標「已匯入」。作者標的名稱（或所在的世界書條目名稱）看起來露骨的圖照樣列出，分類旁邊會有紅色三角形提醒（點一下說明原因），分組標題也會顯示有幾張；要不要匯入由你決定。
  - 立繪變成角色的立繪，角色說話時用作者的圖上台；插圖變成特殊場景圖，AI 會在合適的場面用 `[CG:名稱]` 放出來；背景變成場景背景。
  - **下載在「生成工作」裡進行**：按「開始下載」後關掉視窗也會繼續，可以暫停（下載完目前這張就停）、繼續或停止，進度在清單上方與角落的工作列。
  - **不怕下載不完整**：每下載完一張就存起來，並記下這張圖的來源網址，所以中途停止、關掉網頁或斷線，已經下載的都還在；之後再按「匯入」只會勾剩下的。每張圖下載後會檢查檔案是否完整、能不能正常打開，壞掉的標「失敗」、不會存；失敗的可以在清單裡重新勾選，或在完成通知按「重試沒下載到的」。
  - **復原上一次匯入**：拿掉上一次匯入加進來的圖，被換掉的圖放回原本的，停用的世界書條目重新打開。
  - 可以同時停用作者的圖片清單、插圖輸出規則與自製狀態欄（本程式有自己的立繪、插圖與狀態欄），之後可以在「編輯角色卡 → 世界書」重新打開。
  - 匯入的圖和其他立繪一樣存在這個瀏覽器裡的角色卡上（不是另外的資料夾），會包含在完整備份與素材包裡。
  - 序章只是作者說明或圖片的卡，開始時改選其他序章。
- **作者的設定與規則**：作者寫在角色卡裡給 AI 的提示詞與說明，和 chub.ai 的「Definitions」一樣列出來：作者需知、Character Note、系統提示、後置指示、角色描述、性格、情境、對話範例，以及世界書的每一條（輸出約束、插圖規則、文風、狀態欄這類常駐條目排前面，可以篩選常駐／關鍵字／已關閉，條目多時可以搜尋）。本程式本來就照著用，這裡讓你看得到；世界書的每一條都能直接開關，作者標「选开／選開」的就是給玩家自己選的。作品頁、遊玩前設定與遊玩選單都能打開。
- 成人內容預設隱藏，可在篩選或設定中開啟（僅限成年者）。
  - ⚠️ **注意**：隱藏是依 chub.ai 上作者自己標示的分類篩選。有些角色卡沒有正確標示，所以**就算關閉成人內容，仍可能看到 NSFW 的角色卡、封面或內容**。請自行斟酌，未成年者請勿使用。
- **書架**：上方「繼續遊玩」列出所有存檔（包含還沒加入書架的作品），按「編輯」可以重新命名、複製成新存檔、匯出遊玩檔案或刪除；下方格子是書架上的作品。也支援匯入本機的 `.png`／`.json` 角色卡、世界書，以及別人分享的書本與遊玩檔案（拖曳到視窗即可）。

## 文字模型設定範例

| 服務 | API 類型 | API 網址 | 模型範例 |
|---|---|---|---|
| 免費試玩（Pollinations） | OpenAI 相容 | `https://text.pollinations.ai/openai` | `openai`（免金鑰） |
| Google Vertex AI | Vertex AI（經本機伺服器） | 不用填，地區填 `global` | `gemini-4-argon`、`gemini-3.8-flash` |
| Google Gemini | Gemini 原生 | `https://generativelanguage.googleapis.com/v1beta` | `gemini-4-argon`（按「取得列表」看你的金鑰能用哪些） |
| DeepSeek | OpenAI 相容 | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Anthropic Claude | Anthropic 原生 | `https://api.anthropic.com/v1` | `claude-opus-5-5` |
| OpenRouter | OpenAI 相容 | `https://openrouter.ai/api/v1` | 依網站列表 |
| 中轉站（new-api 等） | OpenAI 相容 | 中轉站提供的網址 | 依中轉站 |
| Ollama／LM Studio | OpenAI 相容 | `http://localhost:11434/v1`／`http://localhost:1234/v1` | 本機模型名 |

按「取得列表」可以直接從 API 抓模型清單，之後就能從下拉選單挑模型（Vertex AI 會自動抓）；清單裡沒有的選「自訂」直接輸入。

其他實用設定（設定 → 文字模型）：
- **思考程度**：自動／關閉／低／中／高。思考會占用「單次回覆上限」並計費。gemini-4-argon 不能完全關閉思考（選「關閉」會自動改用最低等級），gemini-3.8-flash 可以；模型不接受某種寫法時，程式會自動換成可用的並記住。
- **顯示思考摘要**：等待時顯示模型目前在想的標題。
- **單次回覆上限、上下文長度、溫度、Top P**：留空的用模型預設值。

## 用量與費用估算

「設定 → 用量與費用估算」記錄每個模型今天／本月／全部的請求次數、輸入、輸出、思考 token 與圖片張數，並依單價估算費用（只記這個瀏覽器發出的請求）。單價可以自己改；內建的只是參考價，各家價格會調整，請以服務商公布的價格與實際帳單為準。

**Vertex AI（Google Cloud）**：
- 金鑰是 Google Cloud 的服務帳戶金鑰（.json）。server.js 會用它向 Google 換存取權杖、代為送出請求，金鑰本身只留在這台電腦，不會進到瀏覽器。
- 金鑰檔放進本程式的 `keys` 資料夾，會用裡面最新的服務帳戶 .json（這個資料夾不會上傳到 GitHub，也不會提供給網頁）。要指定別的檔案，就在 `config.local.json` 的 `vertex.keyFile` 填路徑，或設定環境變數 `GOOGLE_APPLICATION_CREDENTIALS`；要用金鑰以外的專案，就填 `vertex.project`。程式不會到這台電腦的其他資料夾找金鑰。
- 一定要用「啟動漫劇卡.bat」開啟（直接開 index.html 不能用）。黑色視窗會顯示找到的金鑰檔名，設定頁也會顯示連上的專案。
- 地區預設 `global`（`aiplatform.googleapis.com`），新模型通常只在這裡有。
- 圖像模型每分鐘能畫的張數有限（新帳戶通常更少），常會回「HTTP 429 Resource exhausted」。程式會自動等待重試，並在被限流後改成一張一張畫，所以第一次準備立繪可能要好幾分鐘；可以先按「先開始，背景繼續畫」。立繪畫好就存在角色卡上，之後不用再畫。
- 文字模型回「HTTP 429：Resource exhausted. Please try again later.」通常代表 Google 這個模型的**共用算力暫時不夠**，不一定是額度用完。剛上線、熱門的大模型最容易遇到，換成較輕量的模型（例如 Flash）通常就好了。程式會等 2、5、10 秒自動重試三次，畫面顯示「模型忙線中（HTTP 429），約 N 秒後自動重試（第 N/3 次）」；同一個模型的其他請求也會一起等，不會擠在同一秒重試。三次都不行就過一會兒再重試，或改用較輕量的模型。
- 出現「Vertex AI API has not been used / disabled」時，到 Google Cloud 控制台替這個專案啟用 Vertex AI API；出現權限錯誤時，服務帳戶需要「Vertex AI 使用者」角色。

**Gemini 原生**：金鑰從 Google AI Studio 取得。設定頁會多一個「Gemini 安全過濾（Safety Settings）」：關閉（OFF）、不封鎖（BLOCK_NONE）或 Google 預設值；關閉後 Google 仍保留少數無法關閉的基本過濾。出現「HTTP 402／額度已用完」代表金鑰所屬專案的預付額度用完了，要到 AI Studio 替該專案儲值或開啟計費，程式這邊無法處理。

## 作品設定：登場人物、立繪、主角、特殊場景、背景

每個作品（書）都有自己的「作品設定」，**不用進入故事也能設定**：書架上每本書右上角的「⋯」、作品頁的「遊玩前設定」段落、點存檔時的遊玩前設定、繼續遊玩的編輯選單、素材庫都能打開；遊玩中則在選單（齒輪）裡。分成五頁：

- **角色（角色池）**：作品自帶的**登場人物名單**，也就是角色池。第一次開始故事前，AI 會從角色卡（描述、情境、序章、世界書）整理出所有主要角色的名字、別名、關係、資訊與外貌，之後劇情、立繪、角色狀態都用同一份名單：AI 一律用名單上的名字，劇情裡寫「明雲」「店主」「白師兄」也會對到同一個角色，不會變成好幾個人、重複畫立繪。
  - **只有角色池裡的角色有資訊欄**（關係、資訊、好感度、內心話），也只有他們會出現在「角色、立繪與狀態」。守衛、櫃台服務員、店員、士兵這類只用職稱稱呼的路人，就算 AI 替他們寫了狀態也不會顯示。
  - 劇情裡出現了名單外的新角色（AI 登錄了外貌或寫了狀態）時，角色頁會列在「劇情裡出現、還不在角色池」，點一下就加入角色池，劇情裡寫過的外貌、關係與狀態會一起帶進來。
  - 排序：已經登場的角色在前（有立繪的最前），再來是還沒有立繪的，最後是還沒登場的（標「未登場」）。遊玩中「角色、立繪與狀態」只列出已經登場的角色，還沒出場的人只在作品設定看得到。
  - 名單可以自己改、加角色，或按「AI 整理登場人物」重新整理（要求 AI 只回 JSON、思考程度低，避免回覆不完整）；欄位不想自己寫時按「AI 構想關係、資訊與外貌」。
  - 同一個人有兩個名字時（例如名單整理前用了別的名字畫立繪），打開作品設定會自動併到名單上的名字；也可以按「改名或合併到其他角色」手動處理。
  - **從其他角色卡匯入角色**（角色頁的「從其他角色卡匯入」、遊玩前設定、作品頁）：從書架上的另一本書、角色卡檔案（PNG／JSON，也可以是分享的書本檔）或 chub.ai 網址，挑一個角色加進這本書的角色池。關係、資訊、別名、外貌標籤一起帶過來；可以選擇帶立繪（含自訂種類）、世界書裡關於他的條目（變成這本書的附加世界書），單人卡的角色還會帶「角色設定」（描述與性格，提供給 AI，可以在角色頁修改），沒有立繪時可以用角色卡圖片當「平常」立繪。這本書已經有同名角色時只補上沒有的，不會蓋掉。
- **立繪（不限表情，種類自由新增）**：預設 8 種表情，另外可以「新增種類」加入任何表情、動作、姿勢或服裝（例如「拔劍備戰」「揮手打招呼」「便服」「制服」）。AI 拿到每個角色有圖的清單（含說明），台詞寫成 `[SAY:角色名|揮手打招呼]`；寫成「笑著揮手」也會對到最接近的那張。劇場在同一格換上對應的立繪，下半身完整顯示、不會淡出。
  - **匯入**：可以一次選多張；檔名是預設表情就放進那一格，檔名是中文名稱（例如「白明雲_揮手打招呼.png」）會自動新增成那個種類。「匯入時自動去背」會去掉綠幕或單色背景。
  - **生成／依立繪改寫**：點一格，畫法**自由描述**（表情、動作、姿勢、服裝、道具都可以），再選最多 3 張參考圖：任何角色的立繪或表情、主角立繪、特殊場景圖、背景、角色卡圖，或上傳一張圖。第 1 張是要改寫的那張；可以選「保持角色的長相與服裝」。不想自己寫時按「AI 構想畫法」（依名稱、角色資料與作品內容寫好說明與畫法），遊玩中還有「依目前劇情撰寫」。「用『平常』生成缺少的」一次補齊所有空格。新增種類、特殊場景、背景的表單也都有「AI 構想」。
  - 需要能看參考圖的服務（Vertex AI／Gemini nano-banana、對話式圖像模型、gpt-image）。
- **主角**：你扮演的主角也能有自己的立繪（種類同樣可以自由新增）、外貌與設定（可以按「AI 構想主角設定與外貌」依這個作品構想）。主角的立繪存在主角身上，所有作品共用；輪到你的台詞或行動時會站上舞台（可以關掉），畫特殊場景圖（例如擁抱）時也能選主角當參考。
  - **從角色卡匯入主角**（主角頁的「從角色卡匯入主角」，或編輯主角時的「從角色卡匯入」）：用別本書或角色卡裡的角色當主角，名字、設定、外貌、頭像與立繪一起帶過來，之後可以再修改。
- **特殊場景**：有角色的事件插圖。預設有擁抱、牽手、告白、哭泣、受傷、打鬥等空格，也可以「新增種類」。劇情到那個場面時 AI 輸出 `[CG:名稱]`，畫面中央換成這張直式插圖，直到 `[CG:off]` 或換場景。設定頁裡的預覽先模糊處理，點了會先提醒「提前看到可能會影響遊玩體驗」再顯示（素材庫的縮圖也是模糊的）。
- **背景**：實際的場景背景（沒有人物），和特殊場景分開管理。可以「新增種類」、匯入，或依參考圖改寫生成；「AI 從角色卡整理場景」會先列出故事裡的主要地點。換場景時 AI 輸出 `[BG:背景名]`（或 `[SCENE:背景名] 描述`），沒有指定時依場景描述挑最接近的背景。
- **保存**：每一格都能下載；「匯出素材包」把整個作品的立繪、自訂種類、別名、登場人物名單、特殊場景圖與背景存成一個檔，「匯入素材包」可以放回來或放到別的作品。完整備份（設定 → 資料）也會包含這些素材與主角立繪。別的作品裡有同名角色的立繪時，角色頁會提示「套用」一鍵複製過來。
- **依目前劇情生成圖片**（遊玩選單，或作品設定裡從遊玩中打開時的「依目前劇情改寫／生成」）：AI 讀最近的劇情，替「這個角色此刻的表情或動作」「這一刻的特殊場景圖」或「目前地點的背景」寫好名稱、說明與畫法，參考目前的立繪或背景改寫生成；可以勾選畫好後直接套用到目前這一句。
- **素材庫**（「我的 → 素材庫」）：所有作品的立繪、特殊場景圖、背景集中列出，可以直接編輯、匯出、匯入或清除，也管理音效庫。
- 預設進入故事時不畫立繪（沒有立繪的角色用角色卡圖片演出）。想恢復「新角色登場就自動畫立繪」，到「設定 → 圖像生成」打開「自動生成角色立繪」。
- **圖像安全過濾與生成結果**：「設定 → 圖像生成」有自己的安全過濾設定，預設關閉（連同 Vertex AI 針對圖片的類別）。請求的寫法：參考圖在前、文字在後，temperature 0.95。Google 仍保留無法關閉的圖片審查，部分內容會被拒絕（回報 IMAGE_SAFETY）。
  - 每次生成完都會回報結果：畫好了（附上模型的文字回覆），或沒畫出來的原因（例如「圖片安全審查（IMAGE_SAFETY）」與模型的回覆）。沒畫出來時會跳出提示，作品設定與「生成工作」列表也會留著。
  - **不會自動重試**：由你決定要不要按「修改後重試」，它會帶著上次的畫法與原因重新打開設定；可以自己改，或按「改寫成含蓄的畫法」讓 AI 把畫法改得含蓄一些再畫一次。

## 優先指示與遊玩前設定

**優先指示**是你自己寫給 AI、比其他規則都優先的指示，每回合放在給 AI 的指示最後面（仍然使用分鏡格式、遵守成人內容的年齡規定）。分成五類：
- **要記住的事**：一直成立的事實，例如「主角的左手受了傷」「瑟拉答應過要保守秘密」，避免 AI 忘記或前後矛盾。
- **劇情走向**：接下來的發展方向，例如「慢慢推進感情線」。
- **輸出方式**：文風、長度、對話與旁白的比例，例如「多寫對話，旁白精簡」。
- **禁止事項**：絕對不要出現的內容，例如「不要讓主要角色死亡」。
- **其他**。

指示分三層，可以同時用：**所有故事**（預設，在「設定 → 劇情 → 編輯優先指示」）、**這個作品**（作品的所有存檔共用）、**這個存檔**。每一條都能單獨開關或刪除；同一類有衝突時，以越貼近這個存檔的為準。「從範本加入」有常用的輸出方式與禁止事項；「AI 整理要記住的事」會讀這個存檔的劇情列出要記住的事；「AI 構想劇情走向」會提出三個方向讓你挑。

**遊玩前設定**：點「繼續遊玩」或作品頁的存檔時，會先出現這個畫面，可以調整優先指示、角色池與立繪（也可以從其他角色卡匯入角色）、主角、特殊場景與背景、配樂，看作者的設定與規則，再按「繼續遊玩」。不想每次都看到，可以在畫面裡關掉「點存檔時先顯示這個畫面」（或在「設定 → 劇情」），之後從存檔選單的「遊玩前設定」打開。作品頁的「遊玩前設定」段落、書架上每本書的「⋯」也能打開；遊玩中在選單的「優先指示」。

## 配樂（BGM）與音效（自己匯入音檔）

本程式不生成音樂或音效，音檔都是你自己匯入的；AI 只會拿到有音檔的種類。**配樂庫每本書分開**，音效庫所有書共用。

- **配樂**：每本書有自己的配樂庫，只在那本書播放（遊玩選單的「這本書的配樂庫」、遊玩前設定、作品頁的「配樂」都能打開）。預設有日常、溫馨、歡樂、浪漫、悲傷、緊張、戰鬥、神秘、恐怖、搞笑、夜晚、雨天、史詩、結局等種類，點「匯入」放音樂，也可以「新增種類」。故事開始、換場景或氣氛改變時，AI 輸出 `[BGM:名稱]` 換配樂（循環播放、換曲時淡入淡出），`[BGM:off]` 停止。往回看歷史時配樂也會跟著換成那時候的。劇場右上角的 ♪ 可以開關配樂（這本書的配樂庫是空的時候會打開它）。
  - 配樂庫下方列出「其他書的配樂」：按「加入這本書」複製一份過來，之後兩邊各自獨立。
  - 每本書的配樂庫可以「匯出這本書的配樂」或「匯入配樂檔」；刪除一本書時，它的配樂一起刪除。
- **音效**：劇情裡的 `[SFX:音效名] 擬聲詞` 會從音效庫挑一個音檔播放；畫面上只在字幕上方淡淡出現「♪ 擬聲詞」。沒寫音效名時，依擬聲詞內容比對（例如「叩叩叩」→敲門）。預設有敲門、開門、腳步聲、心跳、刀劍、打擊、爆炸、雷聲、雨聲、風聲、鐘聲等種類。
- 「批次匯入」會依檔名分類（例如 `door_knock.wav`、`敲門聲.mp3` 歸到敲門，`mystery_theme.mp3` 歸到神秘，其他檔名自成一類）。
- 開關與音量：「設定 → 聲音」，或各個配樂庫、音效庫裡（開關與音量所有書共用）。素材庫依書列出配樂，也可以匯出／匯入音效庫。

## 暫停與停止生成

- **劇情**：生成中，行動框（劇場）或送出鍵（漫畫／小說）變成「暫停」。暫停會保留已經寫好的句子（寫到一半的那句先丟掉），之後按「繼續生成」從中斷處接著寫；也可以改按「重新生成」或「重新選擇」。
- **立繪、特殊場景圖、背景、場景圖**：每一項都可以暫停（畫完目前這張就停，按「繼續」往下畫）或停止（中斷請求、放棄剩下的）。作品設定、遊玩前的準備視窗都有按鈕；切到其他畫面時，角落的「生成中」工作列可以統一管理（也可以從遊玩選單「生成工作」打開）。

## 場景圖（選用）

| 服務 | 說明 |
|---|---|
| Vertex AI | 例如 `gemini-nano-banana-2.1`；用本機伺服器的 Google Cloud 金鑰，不用另外填；可附參考圖，最適合畫表情組 |
| Gemini（原生） | 例如 `gemini-nano-banana-2.1`；金鑰沒填時沿用文字模型的 Gemini 金鑰；可附參考圖 |
| Pollinations | 免費、免金鑰；每個 IP 約 45 秒一張，程式會自動排隊等待 |
| OpenAI 相容圖像 API | `/images/generations`，例如 `gpt-image-1`；可附角色參考圖 |
| 對話式圖像模型 | 透過 `/chat/completions` 回傳圖片的模型，可附角色參考圖 |
| Stable Diffusion WebUI／Forge | 啟動參數加 `--api --cors-allow-origins=*`（或用 server.js 代理） |
| ComfyUI | 啟動參數加 `--enable-cors-header "*"`；可貼上自己的 API 格式工作流程 |

「設定 → 圖像生成 → 生成場景圖」可以關掉：關掉後不畫場景，背景直接用角色卡圖片，圖像服務只用來畫立繪與表情。開著時預設「場景圖只畫背景、人物用立繪」，也可改成人物與背景畫在同一張。故事頁可填主角色的「外貌標籤」（或按 AI 自動產生），劇情中新角色登場時 AI 也會登錄外貌，用來畫立繪。

本程式不生成配樂；想要背景音樂可以自己匯入到配樂庫（見上方「配樂（BGM）與音效」）。

## 遊玩功能

- **劇場模式**：電腦上鋪滿整個視窗，手機上直式全螢幕。
  - 舞台有左右兩個固定站位：說話的人亮起、另一位變暗，只有一人時站中間；角色在場時背景會模糊。特殊場景圖出現時，立繪淡出、插圖置中。
  - 台詞一行一行推進：電腦上是畫面中央的大字、整句淡入，手機上在下方靠左、名字下有底線。可在「設定 → 劇情」改成打字機逐字，並調整自動播放速度。
  - 上方狀態欄收起時**只有目前角色**（說話中的角色；旁白或路人說話時是最近說話的角色池角色）的頭像、名字與好感度，有新的內心話時亮紅點。點一下展開下面的面板，就是完整的「角色、立繪與狀態」：主角狀態（時間、地點、行程…），以及角色池裡所有已登場角色的卡片（關係、資訊、好感度、內心話），目前角色排最前面、金框標出；卡片的齒輪可以改外貌標籤、朗讀聲音和立繪。再點狀態欄或面板上的 ⌃ 收起。數值變化只提示主角狀態與目前角色的。選單的「角色與狀態」是同樣的內容。
  - **結局**：只有整段沒有選項、以 `[END]` 收尾的回覆才算結局（模型常把 `[END]` 當成「這段寫完了」，同一段又給了選項，那種不算）。每個結局畫面只自動跳出一次，之後再看到那一句只顯示「結局：名稱」。
  - 右上角：AUTO（自動播放）、朗讀、眼睛（隱藏介面看圖）、時鐘（劇情回顧）、齒輪（選單；也可以按 Esc）。
  - **點畫面左側＝上一句，右側＝下一句**（鍵盤 ←／→）。**左下 «／右下 »＝上一個／下一個選擇點**（鍵盤 Shift＋←／→）；手機上選擇時，« 在選項下方的「上一個選擇點」。
  - 每段劇情播完出現選項（寬螢幕在右側中間、手機在狀態欄下方），另有「自動進行」與輸入框。選項出現後仍可點左右側往回看這回合的台詞，選項會一直留著。
  - **AI 思考或生成中也能往回看**：點左側或按 « 回到之前的劇情與選擇點，按「回到最新」或 » 回來，新的句子會自動接上。開啟「顯示思考摘要」時，等待中會顯示模型正在想什麼。
  - **回到過去的選項**：按 « 到以前的選擇點，會顯示當時的選項，金框標出你當時選的；改選別的選項（或輸入新的行動、按自動進行）就從那裡重來，可以先把原本的進度「另存分支」，之後從「存檔列表」回去。
  - **每個回合都能重新選擇**：看任何一個回合的劇情時，上方都有一行「▸ 你當時的行動」和「重新選擇 ▾」，展開就是那個選擇點當時的選項（標出當時的選擇），點另一個就從那裡重來（同樣可以另存分支），或選「回到這個選擇點，自己輸入」。最新回合還在生成或生成失敗時，「重新選擇」會直接停止並回到選項，自己打的字放回輸入框。
  - 最新回合的行動框另有重新生成、暫停／繼續生成。
- **返回上一步**：從遊玩畫面打開設定、作品頁等再按返回，會回到原本的畫面與同一句台詞；探索、書架、我的、設定這些分頁從故事打開時，左上角也會有返回鍵。遊玩選單打開的面板（角色與狀態、立繪、音效庫、前情提要、存檔列表、匯出）左上角的 ← 會回到選單。
- **漫畫模式**（條漫捲動、對白泡泡）與**小說模式**（純文字回顧）。
- 輸入台詞或行動（`*動作*`、`「台詞」`），或點 AI 提供的選項；支援語音輸入（Chrome／Edge）。
- 朗讀（瀏覽器內建語音，可為每個角色指定聲音）、自動播放。
- 重新生成（可左右切換版本）、編輯、從任一則訊息建立分支存檔、回到某句重來。
- 數值（好感度等）、結局收藏、成就。
- **長期記憶**：對話超出上下文時，舊劇情會自動濃縮成「前情提要」。
- 匯出劇情為純文字、SillyTavern 聊天紀錄（.jsonl），或可以分享、可以匯入的遊玩檔案（見下一段）。

## 分享書本與遊玩檔案

- **匯出書本**（作品頁的「匯出書本（分享）」或「⋯」選單）：角色卡與世界書一定包含，可以選擇一起包含立繪、特殊場景圖、背景、這本書的配樂、勾選的存檔（連同劇情裡的場景圖），以及存檔用的主角（名字、設定、外貌與主角立繪）。存成一個 `.json` 檔。
- **匯出遊玩檔案**（存檔的選單、遊玩選單的「匯出劇情」）：同樣的檔案，預先勾好那個存檔。
- **匯入**：書架的「匯入」或直接拖曳到視窗。會先列出檔案裡有什麼：
  - 書架上已經有同一本書（同一張 chub.ai 卡，或名字、作者、描述都一樣）時，可以選「加進這本書」：存檔加進去，立繪、場景圖、配樂只補上你沒有的，不會蓋掉你的；或選「匯入成另一本書」。
  - 對方的主角你這裡沒有時，可以一起匯入；關掉的話存檔改用你的預設主角。
  - 存檔都用新的編號加進來（同名的存檔名稱後面加「（匯入）」），同一個檔匯入兩次也不會蓋掉。

## 成人內容（僅限成年使用者）

「設定 → 劇情 → 成人內容」開啟後，劇情自然發展到成年角色之間的親密場景時，AI 不會刻意淡出或跳過。這只適用於明確已成年（18 歲以上）的角色：角色未成年或年齡不明時，程式會要求 AI 絕不描寫任何性相關內容。使用 Gemini 時，回應可能被 Google 的安全過濾擋下，可以在「設定 → 文字模型」調整安全過濾。

## 角色卡支援程度

支援：V1／V2／V3、PNG／JSON、開場白與替代開場白、系統提示、後置指示、對話範例、Character's Note（depth_prompt）、常用巨集（`{{char}}` `{{user}}` `{{random}}` `{{roll}}` `{{getvar}}`／`{{setvar}}` 等）、世界書（關鍵字、正則關鍵字、次要關鍵字邏輯、常駐、機率、遞迴、插入位置、預算）。

不支援（會保留在匯出檔中，但不執行）：正則腳本、酒館助手腳本、EJS 模板、角色卡內附的表情包（表情改由圖像模型畫）。

## AI 輸出的分鏡格式

```
[SCENE] 中文畫面描述 ## English image prompt（也可以寫 [SCENE:背景名] 描述）
[BG:背景名] 換成作品的背景圖（只有作品有背景圖時才會用）
[BGM:配樂名] 換配樂（[BGM:off] 停止；只有配樂庫有音樂時才會用）
[NARR] 旁白
[SAY:角色名|表情或動作] 台詞（預設表情或這個角色的自訂種類，例如 拔劍備戰）
[THINK:角色名] 內心獨白
[SFX:音效名] 擬聲詞（從音效庫挑音檔播放；沒有音效名時寫 [SFX] 擬聲詞）
[CAST:角色名] English appearance tags
[STAT] 好感度 +5（文字狀態：[STAT] 時間 = 第三天・深夜）
[STAT:角色名] 關係 = 初識的客人（角色狀態；「資訊」「內心話」也用這個）
[CG:名稱] 顯示特殊場景圖（[CG:off] 收起；只有故事裡有特殊場景圖時才會用）
[CHOICE] 選項一 || 選項二 || 選項三
[END] 結局名稱
```

模型沒有完全照格式時，程式會把一般小說文字自動拆成旁白與對白。提示詞可在「設定 → 劇情 → 進階」修改。

## 安全性設定

所有安全性設定都由使用者決定，集中在兩個地方：本程式資料夾的 `config.local.json`（本機伺服器、金鑰），以及設定頁（瀏覽器端）。

**`config.local.json`**（範本：`config.example.json`；改了伺服器的設定要重新啟動 .bat 才會生效）：

| 設定 | 預設 | 說明 |
|---|---|---|
| `server.port` | `8787` | 本機伺服器的連接埠（也可以用環境變數 `PORT`）。 |
| `server.lan` | `false` | 讓同一個 Wi-Fi 的裝置（手機）連線；也可以用 `--lan` 或雙擊「手機也能連」的 .bat。開啟後，區網裡的裝置都能透過這台電腦使用代理與 Vertex AI 額度，請只在信任的網路開啟。 |
| `server.proxy` | `true` | 本機 API 代理（避開瀏覽器的跨域限制）。關掉後瀏覽器直接連各家 API，部分服務會連不上。 |
| `server.proxyPrivate` | `true` | 代理可不可以連到本機或區網位址。Ollama、LM Studio 等本機模型需要；不用本機模型時可以關掉。 |
| `vertex.keyFile` | （空） | Vertex AI 金鑰檔路徑；留空時用 `keys` 資料夾裡最新的服務帳戶金鑰。 |
| `vertex.project` | （空） | Google Cloud 專案 ID；留空時用金鑰檔裡的。 |

**設定頁**：

| 設定 | 位置 | 預設 |
|---|---|---|
| 透過本機代理送出請求 | 設定 → 網路 | 自動（有本機伺服器就用） |
| Gemini／Vertex AI 文字安全過濾 | 設定 → 文字模型 | 關閉（OFF） |
| 圖像安全過濾 | 設定 → 圖像生成 | 關閉（OFF） |
| 成人內容 | 設定 → 劇情 | 關閉 |
| 探索顯示成人內容（NSFW） | 探索 → 篩選 | 關閉 |
| 匯出完整備份時包含 API 金鑰 | 設定 → 資料 | 每次詢問，預設不含 |

成人內容只適用於明確已成年的角色：角色未成年或年齡不明時，程式一律要求 AI 不描寫任何性相關內容。這條規定是固定的，不能關閉。

**本機伺服器（server.js）的保護**：
- 代理、Vertex AI 與 `config.local.json` 只接受漫劇卡自己網頁發出的請求；其他網站（包含藏在圖片、表單裡的請求）與 DNS rebinding 都會被擋下。
- 代理不能連回這個伺服器自己，避免被拿來讀取設定或借用額度。
- 只提供網頁需要的檔案類型；`.json`、`keys` 與 `private` 資料夾、腳本、隱藏檔都不會被提供。
- Vertex AI 金鑰只在 server.js 使用，不會送到瀏覽器；只從 `vertex.keyFile`、環境變數 `GOOGLE_APPLICATION_CREDENTIALS` 或 `keys` 資料夾讀取，不會搜尋電腦的其他資料夾。

**不會上傳到 GitHub 的檔案**（`.gitignore`）：`config.local.json`、`keys` 資料夾裡的金鑰、`private` 資料夾（放自己的測試腳本、圖片等）。

## 資料與隱私

- 角色卡、存檔、立繪、特殊場景圖、音效庫、場景圖、設定（含 API 金鑰）都只存在這個瀏覽器的 IndexedDB；`config.local.json` 則是你電腦上的一般檔案。完整備份會包含立繪、特殊場景圖與音效庫。

- 換電腦或清除瀏覽器資料前，請到「設定 → 資料」匯出完整備份。
