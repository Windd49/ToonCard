# 漫劇卡 ToonCard

**把角色卡變成可以遊玩、可以收藏、可以分享的互動漫劇。**

你扮演主角，AI 演出角色與旁白：角色以立繪登場、隨台詞換表情，劇情走到關鍵場面時換上插圖，匯入自己的音樂後，配樂也會跟著氣氛切換。每段劇情結束，你都能選擇接下來怎麼做，或直接輸入自己的台詞與行動。

角色卡可以從 chub.ai 探索，也能匯入自己的檔案。從挑選角色、準備畫面，到保存不同進度、把故事分享出去，都能在同一套介面裡完成。

> **開發中**：功能與介面持續調整，可能遇到錯誤。目前僅以 Gemini API 與 Vertex AI 測試，其他服務的相容性仍待確認。

> **設計參考**：本專案的操作介面與互動設計參考了既有的 AI 互動漫劇與角色扮演工具；與相關產品及平台無隸屬或官方合作關係。

## 你是不是也想要……

- 用自己選的 AI 模型玩角色卡，花多少錢由自己決定？
- 想自己架一套 AI 視覺小說，又不想花太多時間研究設定？
- 玩到最後，最想留下來的其實是劇情裡那些畫面？
- 把一路玩出來的故事和圖，分享給朋友一起看、一起玩？

漫劇卡就是為這些需求做的。你可以先用一張角色卡開始，再慢慢替故事補上自己的角色、畫面與聲音。

## 漫劇卡可以帶給你什麼？

### 用自己選的模型，決定怎麼玩、花多少錢

文字與圖像服務可以分開選擇，使用自己的 API，也能設定本機模型。程式本身免費、開源，外部服務的費用直接依服務商計算；「用量與費用估算」可查看各模型的請求與用量，並自行調整參考單價。

### 讓角色卡在畫面裡演出

劇場模式中，角色在舞台左右登場，說話的人亮起、另一位變暗，隨對話切換立繪；到了特殊場景，畫面換成事件插圖。喜歡一次讀完，也能切成漫畫條漫或小說回顧，搭配自動播放與瀏覽器語音朗讀。

### 畫面會留下來，故事可以慢慢養成

立繪、插圖與背景可自行匯入，也可用圖像服務生成，保存後留在作品裡反覆使用。除了預設表情，還能新增「揮手」「拔劍」「便服」等動作、姿勢或服裝，選擇參考圖，或依目前劇情構想新的畫面。

沒有整套素材也能先開始：缺少立繪時可用角色卡圖片演出，部分卡片還能挑選作者附圖匯入。圖片生成是選用功能，配樂與音效則由你自行匯入。

### 把故事調成自己想要的樣子

可以編輯自己扮演的主角，整理作品的登場人物，也能從其他角色卡匯入角色，組合自己的演出陣容。「優先指示」能記下要記住的事、想走的劇情方向、喜歡的文風與禁止事項，分別套用到所有故事、單一作品或存檔，提供給 AI 作為提示。

### 每個選擇都能回頭，喜歡的進度另存一條路

除了點選 AI 給的選項，也能輸入自己的行動。回到以前的選擇點改選、重新生成某個回合，或把原本的進度另存分支，就能嘗試不同發展。角色關係、好感度、內心話與主角狀態會隨劇情呈現，也能收藏結局。

### 分享整本故事，讓朋友從你停下的地方接著玩

把角色卡、世界書、立繪、插圖、背景與配樂，連同選定的存檔及主角打包成一個檔案。朋友匯入後，就能帶著這些素材與進度繼續遊玩；也可以只分享角色與素材，讓對方開始自己的故事。

## 開始使用

1. 從本頁的 **Code → Download ZIP** 下載並解壓縮，或用 GitHub Desktop 複製專案。
2. 安裝 [Node.js](https://nodejs.org/)，雙擊 **`啟動漫劇卡.bat`**。瀏覽器會開啟 <http://127.0.0.1:8787>；使用期間請保持啟動視窗開著，不需另外安裝 npm 套件。
3. 到 **設定 → 文字模型** 選擇服務，填入自己的 API 金鑰與模型，按「測試連線」。可用「取得列表」挑選帳戶能使用的模型。程式也提供 Pollinations 試玩選項，可用性依該服務而定。
4. 在 **探索** 選擇角色卡，或從 **書架 → 匯入** 載入 `.png`／`.json` 角色卡。進入作品頁可看簡介、選序章與主角，再按「開始新故事」；想保留在書架時，按「加入書架」。

第一次開演前，AI 可以先整理作品的登場人物；「遊玩前設定」則能調整角色、圖片、主角、配樂與優先指示。不必先準備所有素材，開始遊玩後也能慢慢補上。

想用手機玩：雙擊 **`啟動漫劇卡（手機也能連）.bat`**，手機連上同一個 Wi-Fi，再開啟啟動視窗顯示的手機網址。區網模式會讓網路內的裝置使用本機代理與 Vertex AI，請只在信任的網路使用。

## 角色、畫面與聲音怎麼準備？

每個作品都有自己的設定，從作品頁的「遊玩前設定」、書架作品的「⋯」或遊玩選單都能打開。

| 項目 | 可以做什麼 |
|---|---|
| 登場人物 | 整理名字、別名、關係、資訊與外貌；可讓 AI 從角色卡整理，也能自己修改或從其他卡匯入。 |
| 主角 | 設定名字、個性、外貌與立繪，也可匯入角色卡裡的角色作為主角；主角資料可跨作品使用。 |
| 立繪與特殊場景 | 匯入或生成表情、動作、服裝與事件插圖，依對話或劇情切換。 |
| 背景 | 準備故事地點的圖片，也可請 AI 從角色卡整理場景，再選擇匯入或生成。 |
| 配樂與音效 | 配樂按作品管理，音效庫跨作品共用；匯入音檔、設定分類後，由劇情切換使用。 |
| 世界書與作者規則 | 查看角色定義與作者的提示，開關需要的世界書條目，調整作品提供給 AI 的設定。 |

「我的 → 素材庫」可集中管理各作品的圖片、配樂與音效。圖片能個別下載，或匯出素材包，帶到其他作品使用。圖片生成工作可暫停、繼續或停止，不必一直停留在同一個設定畫面。

## 遊玩時的常用操作

| 想做什麼 | 劇場模式操作 |
|---|---|
| 上一句／下一句 | 點畫面左側／右側，或按 `←`／`→`。 |
| 回到上一個選擇點 | 按 `«`，或 `Shift + ←`；`»`／`Shift + →` 前往下一個。 |
| 改選或重新輸入行動 | 展開該回合的「重新選擇」，原進度可另存分支。 |
| 看角色與主角狀態 | 點上方狀態欄展開，查看關係、資訊、好感度與內心話。 |
| 調整素材、存檔與生成工作 | 點齒輪開啟遊玩選單，或按 `Esc`。 |

生成劇情時也能回看已經發生的內容，再回到最新進度。長對話可濃縮成前情提要，讓模型接續故事；實際記憶與演出效果仍取決於模型及角色卡內容。

## 分享、存檔與備份

- **分享一本書**：在作品頁選「匯出書本（分享）」，角色卡與世界書一定包含，其他素材、配樂、存檔與主角由你勾選。
- **分享某個進度**：從存檔選單選「匯出遊玩檔案」，或到遊玩選單的「匯出劇情 → 遊玩檔案」，會預先勾好這個存檔。對方在書架匯入，即可加入既有作品或另建一本。
- **備份自己的全部資料**：到「設定 → 資料」匯出完整備份，再於另一個環境匯入。這與分享單本作品不同，完整備份也包含設定，並可選擇是否包含 API 金鑰。

分享前請確認劇情、主角資料與素材適合公開，且有權分享；含金鑰的完整備份請自行保管。

## 模型與相容性

文字與圖像有各自的設定，提供以下連線方式；**目前僅以 Gemini API 與 Vertex AI 測試，提供設定入口不代表所有服務與模型都已驗證。**

| 類型 | 可設定的服務或介面 |
|---|---|
| Google 文字與圖像 | Gemini 原生 API、Vertex AI；Vertex AI 透過本機伺服器使用 Google Cloud 服務帳戶金鑰。 |
| 其他文字服務 | Anthropic 原生 API、OpenAI 相容 API，可設定 OpenAI、DeepSeek、OpenRouter 或相容中轉服務。 |
| 本機文字模型 | Ollama、LM Studio 等提供相容介面的服務。 |
| 其他圖像後端 | OpenAI 相容圖像 API、對話式圖像模型、Stable Diffusion WebUI／Forge、ComfyUI。 |

模型名稱、可用性、費用、額度與內容限制依服務商而定。建議用「取得列表」選擇帳戶能使用的模型，先測試連線，再開始準備大量素材；參考圖與圖像編輯等功能也依服務而異。

角色卡支援 **V1／V2／V3、PNG／JSON、替代開場白、常用巨集與世界書**。不執行內附的正則腳本、酒館助手腳本或 EJS 模板，也不直接套用卡片內附的表情包，因此部分效果可能與原平台不同。

## 已知問題與目前限制

目前已有世界書觸發、優先指示、前情提要與畫風設定，但劇情和許多狀態變化仍由 AI 判斷，可能出現停滯、偏離主線、人物突然出場、前後矛盾或長篇遺忘。下面幾項也已在程式檢查中確認：

- **文字狀態可能被誤讀成數字**：例如 `[STAT] 時間 = 08:30` 目前會變成 `8`，`地點 = 3號教室` 會變成 `3`。預計先修正數值判斷，再加入文字、數值與劇中時間的明確型別。
- **改寫舊劇情後，前情提要可能仍保留舊內容**：編輯或切換已被摘要涵蓋的回覆，尚未自動重建相關摘要。目前可在「前情提要」手動更正；預計加入來源版本與失效重建。
- **不同繪圖入口的參考圖能力尚未統一**：手動立繪／事件圖可使用參考圖，自動完整場景的角色參考圖目前只在部分後端組裝。預計共用能力檢查，並在送出前顯示實際附圖情況。
- **世界書並非所有進階規則都相容**：已有關鍵字、常駐、機率與遞迴，但尚未實作 sticky／cooldown／delay 等計時效果。預計提供匯入相容性與觸發原因的檢查介面。

仍有待跨模型、長篇與不同角色卡實測的問題，歡迎提供可重現的案例。核對依據與暫時做法見 [已知問題與發展規劃](docs/ROADMAP.md)。

## 作者希望發展的介面與玩法

以下是希望逐步加入的方向與預計解法，**尚未實作，也沒有固定完成時程**：

| 方向 | 目前的基礎與限制 | 預計解法與介面 |
|---|---|---|
| 可觸發、可生成草稿的事件 | 世界書與優先指示能引導 AI，但尚無持久的事件進度、前置條件與完成判定。 | 新增事件編輯與試算面板，設定條件、主線節點、一次性／冷卻及成功／失敗效果；AI 提供草稿，由作者確認，程式判定規則，AI 負責演出。 |
| 分享挑戰、目標與競賽 | 已有分享書本、存檔與分支，尚無回合限制、指定事件目標或排行榜。 | 設定回合上限、單一必達目標或多個不同目標，顯示進度並綁定特殊場景；先做同一起點的本機挑戰分享與結果卡，再評估選用的線上競賽／排行榜。 |
| 人物出場、時間軸與行程 | 已有角色池、曾登場名單與 AI 輸出的時間／地點，尚無統一劇中時鐘與角色行程規則。 | 新增世界狀態與人物行程面板，記錄位置、正在做的事、可出場條件與截止時間；依有效行動推進時間，到期結算成功、錯過或失敗分支。 |
| 劇情一致性與畫風提示詞 | 已有摘要、要記住的事、多種畫風、自訂提示詞與參考圖，仍可能遺漏事實或產生風格衝突。 | 新增有來源的故事記憶、狀態變更確認與衝突提示；畫風、角色外貌和場景分欄，提供模型適用範本、最終提示詞預覽與生成紀錄。 |

限制回合可以讓目標更集中，但仍需搭配記憶與狀態管理，不能保證消除幻覺或失憶。競賽也需要明確的回合、重試與回溯規則；特殊場景圖片的出現，須搭配事件條件驗證才能算通關。

建議順序是 **先修資料一致性 → 事件與世界狀態 → 本機共享挑戰 → 評估線上排行榜**。各介面的欄位、例子、驗收方式與程式依據，見 [完整發展規劃](docs/ROADMAP.md)。

## 資料與使用提醒

- **定期備份**：存檔、素材與設定主要存在目前瀏覽器的 IndexedDB。換電腦、換瀏覽器或清除網站資料前，請到「設定 → 資料」匯出完整備份。直接開 `index.html`、本機網址與手機瀏覽器的資料不會自動互通。
- **連線與金鑰**：使用 AI、探索或外部素材時，會連線到所選服務與素材來源。`config.local.json` 和 `keys/` 中的金鑰已列入 Git 忽略規則；含金鑰的設定或完整備份請勿公開分享。
- **內容限制**：本專案僅供成年使用者。成人內容與 NSFW 探索預設關閉，但外部角色卡的標示可能不完整，仍可能出現不適合的素材；生成結果也可能有錯誤或不符合預期。
