# 漫劇卡使用指南

[返回專案首頁](../README.md)

## 啟動與連線

安裝 Node.js 後，雙擊 `啟動漫劇卡.bat`，以 <http://127.0.0.1:8787> 使用。本機伺服器提供 API 代理，減少瀏覽器跨域（CORS）造成的連線問題，也負責 Vertex AI 驗證；不需另外安裝 npm 套件。

- 更新程式後，關閉啟動視窗，再重新執行 `.bat`。
- 直接開 `index.html` 也能開啟介面，但無法使用本機代理、Vertex AI 或 `config.local.json`，部分服務會因跨域限制連不上。
- 手機使用 `啟動漫劇卡（手機也能連）.bat`，與電腦連上同一個 Wi-Fi，再開啟啟動視窗顯示的手機網址。
- 不同瀏覽器、裝置與網址各自儲存資料，不會自動同步；搬移資料請使用完整備份。

也可在終端機以 `node server.js --open` 啟動，加入 `--lan` 開啟區網模式。區網裝置可能使用這台電腦的代理與 Vertex AI 額度，請只在信任的網路使用。

## 設定檔與 Vertex AI

一般使用可直接在設定頁填入服務、API 網址、金鑰與模型，再按「測試連線」。優先使用「取得列表」選擇帳戶可用模型，內建預設值不保證適用於每個帳戶。

### config.local.json

需要集中管理設定時，將根目錄的 [config.example.json](../config.example.json) 複製為 `config.local.json` 再修改。透過 `.bat` 使用時，修改設定檔後請重新整理網頁；內容有變動會套用一次，之後仍可在介面調整。修改 `server` 設定則需重新啟動伺服器。

設定分為 `llm`（文字）、`image`（圖像）、`story`（劇情）、`audio`（聲音）、`net`（網路）、`chub`（探索）、`server` 與 `vertex`。只需填入想預設的欄位。

```json
{
  "server": { "port": 8787, "lan": false, "proxy": true, "proxyPrivate": true },
  "vertex": { "keyFile": "", "project": "" }
}
```

| 欄位 | 預設 | 用途 |
|---|---|---|
| `server.port` | `8787` | 本機連接埠，也可用環境變數 `PORT` 指定。 |
| `server.lan` | `false` | 允許區網裝置連線；`--lan` 也會開啟此模式。 |
| `server.proxy` | `true` | 啟用本機 API 代理；瀏覽器另可在「設定 → 網路」選擇是否使用。 |
| `server.proxyPrivate` | `true` | 允許代理連到本機或區網服務，Ollama 等本機模型可能需要。 |
| `vertex.keyFile` | 空白 | 服務帳戶金鑰路徑；未指定時依環境變數或 `keys/` 讀取。 |
| `vertex.project` | 空白 | Google Cloud 專案；留空時使用金鑰內的專案。 |

`config.local.json`、`keys/` 內的金鑰與 `private/` 已列入 `.gitignore`。請勿強制加入版本控制，也不要公開分享含金鑰的設定檔。

### Vertex AI

1. 準備已啟用 Vertex AI API、且服務帳戶具備所需權限的 Google Cloud 專案。
2. 指定服務帳戶 JSON 金鑰，讀取順序為 `vertex.keyFile` → 環境變數 `GOOGLE_APPLICATION_CREDENTIALS` → `keys/` 中最新的服務帳戶金鑰。未使用前兩項時，將金鑰放進 `keys/` 即可。
3. 用 `.bat` 啟動，在文字或圖像設定選擇 Vertex AI，設定地區與可用模型後測試。金鑰由本機伺服器讀取並換取存取權杖。

Gemini 原生 API 使用 Gemini API 金鑰，不需服務帳戶檔。文字與圖像服務可分別設定，實際功能與內容限制依服務商而定。

「設定 → 用量與費用估算」記錄目前瀏覽器發出的模型請求與用量，單價可自行調整。估算不等於帳單；思考 token、圖片與重試可能影響費用，請以服務商紀錄為準。

## 角色卡與世界書

- **探索**：瀏覽、搜尋 chub.ai，或貼上角色卡網址。點作品可看簡介、挑選序章與主角，再開始故事；要出現在書架需另外按「加入書架」。
- **本機匯入**：書架可匯入 `.png`／`.json` 角色卡與世界書，也支援拖曳檔案。
- **更新**：作品選單的「從 chub.ai 下載最新版」可更新卡片，保留存檔與立繪。
- **作者的設定與規則**：查看角色定義、系統提示、Character Note 與世界書，並開關需要的條目。
- **作者附圖**：在「遊玩前設定」按「匯入」，勾選圖片並調整名稱、角色與分類，再下載為立繪、特殊場景或背景。工作可暫停、繼續或重試，也能復原上一次匯入。

支援 V1／V2／V3 角色卡、替代開場白、常用巨集與世界書規則。不執行內附的正則腳本、酒館助手腳本或 EJS 模板，這些內容會保留在匯出資料中。卡片附帶的表情包不會直接作為本程式的表情系統使用。

成人內容與 NSFW 探索預設關閉，但外部作者的分類可能不完整，仍可能看到不適合的內容。本專案僅供成年使用者；提示詞與篩選無法保證生成結果。

## 角色與素材

作品頁的「遊玩前設定」、書架作品的「⋯」及遊玩選單都能開啟作品設定：

| 項目 | 可以做什麼 |
|---|---|
| 角色池 | 整理名字、別名、關係、資訊及外貌；可從其他角色卡匯入角色。 |
| 立繪 | 匯入或生成表情、動作、服裝等種類，可選參考圖維持外觀。 |
| 主角 | 編輯自己扮演的角色與立繪，也可從角色卡匯入；主角可跨作品使用。 |
| 特殊場景 | 管理含角色的事件插圖，在故事對應場面顯示。 |
| 背景 | 管理地點圖片，可匯入或用圖像服務生成。 |

「我的 → 素材庫」集中管理素材與音效。圖片可個別下載，或以「匯出素材包」保存並移到其他作品。

未設定圖像服務也能使用自己的圖片。新角色登場時預設不自動畫立繪；需要時到「設定 → 圖像生成」開啟「自動生成角色立繪」。圖像提供 Gemini、Vertex AI、OpenAI 相容介面、對話式圖像模型與本機繪圖後端的設定，參考圖等功能依服務而異。

### 配樂與音效

程式不生成音樂或音效，請自行匯入有權使用的音檔：

- **配樂庫**依作品分開，可新增氣氛分類、匯入與匯出。AI 依劇情切換有音檔的分類，換曲時淡入淡出。
- **音效庫**跨作品共用，依劇情中的音效名稱或擬聲詞挑選音檔。
- 批次匯入依檔名分類；開關與音量在「設定 → 聲音」調整。

## 遊玩與分支

劇場模式逐句演出，漫畫模式以條漫呈現，小說模式適合文字回顧。每回合可選 AI 提供的選項，或自行輸入台詞與行動。

| 操作 | 劇場模式 |
|---|---|
| 上一句／下一句 | 點畫面左側／右側，或按 `←`／`→`。 |
| 上一個／下一個選擇點 | 按 `«`／`»`，或 `Shift + ←`／`Shift + →`。 |
| 重新選擇 | 展開該回合的「重新選擇」，可改選或輸入行動，原進度可另存分支。 |
| 遊玩選單 | 點齒輪或按 `Esc`，調整素材、存檔、優先指示與生成工作。 |

支援自動播放、瀏覽器語音朗讀、重新生成、訊息編輯與分支存檔。長對話可濃縮為前情提要，演出效果取決於模型回覆。

**優先指示**可分別套用到所有故事、單一作品或存檔，設定要記住的事、劇情走向、輸出方式與禁止事項，每條可獨立開關。這些內容會加入模型提示，不保證每次都能遵循。

**生成工作**可從遊玩選單查看。劇情可暫停後繼續生成；圖片可暫停（完成目前項目後停下）、繼續或停止，失敗時可調整內容後重試。

## 分享與備份

| 目的 | 入口與內容 |
|---|---|
| 分享某本故事 | 作品頁「匯出書本（分享）」：角色卡與世界書必含，可選素材、配樂、存檔及存檔用的主角。 |
| 分享某個進度 | 存檔選單「匯出遊玩檔案」，或遊玩選單「匯出劇情 → 遊玩檔案」：預先勾選目前存檔。 |
| 備份全部資料 | 「設定 → 資料 → 匯出完整備份」：包含角色卡、存檔、素材與設定，可選是否包含 API 金鑰。 |

分享檔是 `.json`，從書架匯入；遇到同一本書時可加入既有作品，或另建一本。分享檔不含全域服務設定，但可能包含私人劇情與主角資料，分享前請確認內容與素材使用權限。

完整備份要從「設定 → 資料」匯入，相同項目可能被覆蓋，匯入前先備份目前資料。含 API 金鑰的完整備份請自行保管。

## 常見問題

| 問題 | 處理方式 |
|---|---|
| 找不到 Node.js | 安裝 Node.js 後重新執行 `.bat`；直接開 `index.html` 的連線功能較有限。 |
| API 連不上或遇到 CORS | 使用 `.bat` 啟動，保持啟動視窗開著，檢查「設定 → 網路」的代理設定。 |
| 模型不存在或無權限 | 重新取得模型列表，確認金鑰、專案、地區及帳戶權限。 |
| HTTP 429 | 檢查速率限制、額度與服務狀態，稍後重試或換模型；圖片批次生成可降低並行數。 |
| Vertex AI API 未啟用 | 確認金鑰對應專案已啟用 API，且服務帳戶具備所需權限。 |
| 圖片未生成 | 查看「生成工作」的錯誤與模型回覆，檢查服務設定、額度及內容限制後再試。 |
| 換網址或手機後看不到存檔 | 回到原裝置與網址匯出完整備份，再於新環境匯入。 |

仍有問題時，請到 [GitHub Issues](https://github.com/Windd49/ToonCard/issues) 提供重現步驟、使用的服務與錯誤訊息，並移除 API 金鑰及個人資料。
